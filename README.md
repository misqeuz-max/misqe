# MISQÉ Parfum Boutique

Build a complete premium e-commerce website for my perfume brand **MISQÉ PARFUM**, established in 2026.

I am the founder of this perfume business. This is a REAL perfume store, not a portfolio or landing page.

I have uploaded my official MISQÉ PARFUM logo. Use this exact logo as the main brand identity. **Do not redesign, rewrite, distort, or replace the logo.**

## VISUAL IDENTITY

The website must match the uploaded logo.

Main colors:

* Deep luxury black
* Rich metallic gold
* Warm ivory/cream
* Very subtle dark purple accents only if necessary

The overall feeling should be:
**luxury + elegant + expensive + modern + minimal + premium perfume boutique.**

Do NOT use:

* Bright blue
* Pink gradients
* Cartoon-style elements
* Cheap-looking templates
* Excessive animations
* Generic startup design

Use elegant serif typography for major headings and a clean modern sans-serif font for buttons and smaller text.
